# ACTDrill Product Context

## User

The primary user is an ACT student who may have ADHD, a processing difference,
test anxiety, or limited patience for long lessons. The app should reduce
startup friction and cognitive load without talking down to the student.

## Job

Help the student recognize a finite set of recurring ACT patterns through short,
repeatable practice. The core loop is: see one problem, get a concrete first
move when the brain freezes, choose, understand the trap, name the reusable
pattern, and continue or stop without penalty.

## Voice

Direct, calm, encouraging, specific, and occasionally wry. Praise the action or
the observation, not the person’s intelligence. A wrong answer is evidence for
what to repeat, not a moral event.

## Product principles

- One decision at a time
- Accuracy before speed
- Explanations remain available without AI
- Local-first and credential-free
- Honest status: optional services may be offline
- Keyboard, screen reader, enlarged text, and reduced motion are first-class
- Progress supports practice; it must not overwhelm the lesson

## Anti-patterns

- Homework/test aesthetics
- Marketing language or artificial urgency
- Dense dashboards in the drill path
- Reward noise that competes with the explanation
- Patronizing “you can do anything” copy
- Cloud dependencies for core study
- Running downloaded code without verification

## Success

A student can start a question quickly, use every core path at 200% browser text
equivalent or the 720×560 desktop minimum, understand why an answer works, and
return later with progress intact.
