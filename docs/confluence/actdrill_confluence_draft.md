# ACTDrill 1.18.0

Status: **DRAFT — do not publish without owner review**

ACTDrill is an offline Windows study tool with 280 original ACT-style
questions across 35 English, Math, and Reading patterns. Version 1.18.0 hardens
the desktop trust boundary, verifies question-bank updates as data, restricts
external navigation, verifies the Ollama installer publisher, repairs
small-window/large-text behavior, and adds executable verification checks.
Read-aloud now translates Math notation and plays one native Windows WAV per
request instead of streaming browser utterance fragments. The WebView media
policy now permits that WAV playback, and version tags build verified GitHub
release assets with a SHA-256 manifest.

Repository: https://github.com/mikedopp/ACTDrill

See the repository README, PRODUCT.md, DESIGN.md, and REPO_NOTES.md for the
operator and release details.
